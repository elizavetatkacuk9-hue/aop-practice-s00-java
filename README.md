Задание 2: Ответы на вопросы по Git
Вопрос: В чем разница между командами git log и git diff?
Ответ:
git log показывает историю комитов (кто, когда и с каким сообщением сохранил изменения).
git diff показывает конкретные разницы и изменения в коде между файлами, ветками или состояниями.
Задание 3: Открытая дискуссия
Что такое программа? Программа — это набор инструкций для компьютера, написанный на языке программирования, который выполняет определенную задачу.
Что такое алгоритм? Алгоритм — это четкая последовательность шагов и правил для решения конкретной задачи за конечное время.
Зачем нужно так много языков программирования? Разные языки создаются под разные задачи и сферы (например, Java — для бэкенда и корпоративных систем, Python — для анализа данных и ИИ, C++ — для высокопроизводительных систем и игр).
Дайте определение алгоритма приготовления борща:
Подготовить и помыть ингредиенты (мясо, свеклу, картофель, капусту, лук, морковь).
Сварить мясной бульон.
Нарезать овощи и сделать зажарку из лука, моркови и свеклы.
Добавить в бульон картофель и капусту, затем зажарку.
Посолить, добавить специи и проварить до готовности.
Дайте определение алгоритма завязывания шнурков:
Скрестить два шнурка и продеть один под другой, затянув базовый узел.
Сделать петлю из каждого шнурка.
Скрестить петли, продеть одну петлю в образовавшуюся дырочку и затянуть.
Является ли инструкция по завязыванию шнурков программой? Нет, это алгоритм для человека. Программой она станет тогда, когда будет записана на языке, понятном исполнительному устройству (например, роботу).
